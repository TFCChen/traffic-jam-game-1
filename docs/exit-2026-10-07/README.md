# 出庫演出驗證（2026-10-07）

紅車先加速直行，尾部離開圍欄後轉入街道，再沿道路駛離。車輪依行程旋轉，車身有小幅轉向側傾，排氣方向跟隨車身。延伸道路沿用原道路的材質與世界座標 UV，補上路緣與標線。

鏡頭短暫跟隨並回到玩家原視角，不修改角度、縮放或儲存設定。結果介面由渲染器完成訊號觸發；另有圖形內容失效時的超時恢復。重玩、下一關、返回編輯器共用淡出轉場。低動態偏好略過演出及鏡頭跟隨。

## 驗證

- `npm test`：遊戲引擎、40 關模型映射、儲存、操作、車身動態、燈光、粒子、編輯器與出庫路徑檢查通過。
- `npm run build`：正式版本建置通過。
- `scripts/verify-exit.mjs`：原生滑鼠與模擬手機觸控，桌面、390×844 手機尺寸、30° 低視角；檢查轉向、駛離、結果時機、鏡頭還原、重玩、試玩返回草稿及正式下一關。
- 截圖檢視：道路材質接縫、轉向時圍欄淨空、車輛路面高度及結果介面。
- 手機驗證使用桌面 Chrome 觸控模擬；實體 iPhone / Android 的效能與瀏覽器差異仍需裝置測試。

`results.json` 保存動畫取樣與流程結果。圖片分別為桌面、手機、低視角的轉彎、街道駛離、結果介面，以及低動態結果。

## 後續方向

保持解謎清晰度，優先深化天氣與材質的互動（雨後道路、玻璃水痕、黃昏窗光），再加入低頻率街景細節。環境反應應有共同的風向與光源，避免各物件獨立隨機閃動。新增效果須保留低動態選項並在實機檢視拖車時的幀時間。
