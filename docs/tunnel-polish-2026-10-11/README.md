# 隧道入口細緻化

2026-10-11；分支 `feature/game-feel`；遊戲版本 `4398c325`。

保留完整灰綠頂蓋、清楚洞口、深色內壁與細入口光帶。新增 0.64 長的實體斜降側翼牆，從洞口高度逐漸收低到路緣；石牆改為四排錯縫分塊、細倒角與輕微色差，兩端分格節奏略有不同。入口增加窄石材門框，屋面接縫改為同色立縫。沒有新增屋頂花園、木平台或大型裝飾。

車輛遮擋結構、通道安全長度和端點算法均沿用；裝飾側翼不承擔生成遮擋。先前道路底座僅補兩段短接縫的共面修正保留。新增側翼斜面及入口外側已接入雨水濕潤效果，通道內仍乾燥。穩定陰影、車流速度、紅車出庫、關卡與小動物未修改。
