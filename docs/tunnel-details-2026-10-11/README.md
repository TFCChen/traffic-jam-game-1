# 隧道街景小配件

2026-10-11，分支 `feature/game-feel`，版本 `42a7fce7`。

兩端主體、頂蓋、石材分格、立柱及底座保持一致，不加斜降側翼。僅在朝車庫的外側牆加入不同小配件：北端是深色金屬壁掛植槽、明確牆面支架、低矮綠植及小銘牌；南端是框式街區導覽板與低位通風格柵。使用既有淺石材、灰綠、深色金屬配色，不加落地量體或屋頂用途。

配件全部是實體厚度幾何，表面分層避免共面黑閃；植槽由牆面支架支撐，不冒充落地花盆。綠植接入既有 Street planting 雨材質；配件金屬、石材與灰綠面使用原有濕潤／四主題光影。沿用材質合批，只新增一批葉片，沒有新貼圖、燈光或逐幀動態。未更動遮擋結構、車流端點、底座共面修正、穩定陰影、紅車動作、關卡與小動物。
