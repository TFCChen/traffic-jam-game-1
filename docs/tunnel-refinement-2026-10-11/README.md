# 隧道辨識度恢復與精簡

版本 `17cf98d8`。使用者否決屋頂花園／木平台方案，認為用途不明，並同意恢復清楚的隧道語言，再降低厚重感。本版保留第二版較低的天花／屋頂與安全深度，恢復連續灰綠頂蓋、淺色石材洞口框與深色內壁，移除屋頂花園、步石、木平台、木格柵與花槽。兩端只在牆面接縫、屋面細縫及入口分格做細微差異，不再改成不同用途的設施。

18 組測試、build 與 40 關解答重播通過。原實體遮擋結構及端點不變，測試仍檢查實際幾何在俯角 30–90 度、整圈每 15 度、雙車道及兩種車長的端點遮擋。四主題展示視角、30 度／180 度最低反向雨景連續 36 張車流與 45 度／144 度另一側外觀已查；連續圖拍到長車完整穿越並進入隧道，未見生成／回收瞬間。UI 與 dist 版本一致，隔離 origin .23 console error／warn 為空。

四主題沿用前輪在隔離 origin 匯入的合成 20 關進度，未改一般 origin 的使用者進度。此次只改隧道裝飾幾何／材質，沒有重做手動九步通關或手機驗證；未改遊戲、車流速度、紅車出庫、動物與陰影濾鏡。外觀仍待使用者驗收。
