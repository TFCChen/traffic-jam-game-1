# 街道兩端有頂通道試作（2026-10-11）

版本 `2c444386`，分支 `feature/game-feel`。使用者同意試作，但兩端建築的份量、位置與造型仍待使用者實際驗收，不代表設計已定案。

道路收回有限長度，保留原瀝青、路緣與標線節奏。兩端採低矮石牆、深綠灰屋頂、收邊、排水管、小窗、入口燈與少量屋頂植栽；車輛起終點位於真實不透明屋頂／牆體後方，正常通行不淡入、不裁切車身。六款雙向車流與 5.2–7.6 的速度變化保留。

建築加入現有主題、投影、反射與雨景系統：日景自然受光，黃昏暖光與長影，夜景窗光及入口補光；雨景外牆／屋頂材質濕潤，開放道路有水坑，通道深處保持乾燥。保留 stableShadowFilter、紅車出庫動作、關卡難度與螢幕邊緣動物通關構圖。

## 驗證

- 18 組測試、正式 build 與 40 關解答重播通過；本機 source、dist 與 UI 版本一致。
- 遮擋測試以實際結構幾何射線檢查兩車道、兩車長、俯角 30–90 度及每 15 度水平角的端點包圍盒角落；陰影測試涵蓋低角度光源及建築完整範圍。
- 完成版本實際九步通關、紅車尾段出庫、動物通關卡與下一關零步已檢查。這不是手動玩完全部 40 關。
- 日／雨／黃昏／夜景展示視角、30 度反向最低視角、另一側屋頂及 390×844／320×568 手機俯視已檢查。反向低視角連續 24 張截圖拍到廂型車出入遮擋，未看到生成／回收瞬間。
- 隔離測試 origin `http://127.0.0.23:4173/` 透過 UI 匯入既有合成 20 關備份以解鎖主題，未更動一般 origin 的使用者進度。該 origin 最終 console error／warn 為空。
- 新增 7 組合併材質批次與 2 盞不投影入口燈；省電模式關閉裝飾燈。未量測真機 FPS。
