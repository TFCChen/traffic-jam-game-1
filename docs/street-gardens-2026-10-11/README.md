# 街角通道第二版：降低量體與不對稱配置

版本 `3a675fbd`，分支 `feature/game-feel`。使用者認為第一版兩棟建築太大且相同，本版降低量體、改變兩端材質與頂部配置，仍待使用者驗收外觀。

- 北端採綠化覆頂、錯位植床、淺色維護步石及低植栽邊緣；南端採暖石材、木平台、木格柵與少量花槽，呼應原車庫的咖啡亭、棚架及花台。
- 移除厚女兒牆、大片深色屋面、設備箱及厚黑底座。屋頂基準由 1.82 降至 1.58，通道長度由 6.45 略縮至 6.25，地面街道共 25.4。保留必要的整車遮擋深度，不宣稱建築已大幅縮短。
- 保留真實不透明結構，花槽與植栽僅為表面設計，不依靠植物遮住生成點。天花高度仍高於車輛測試包圍盒；兩車道、兩種車長在支援的旋轉方向都具備遮擋端點。
- 石材、木材、屋面和植栽延用雨景材質系統，外牆／屋頂受雨、通道深處乾燥，黃昏及夜景入口光跟隨主題，既有陰影濾鏡不變。

## 驗證與限制

18 組測試、正式 build 與 40 關解答重播通過。實際結構射線測試涵蓋俯角 30–90 度每 15 度、水平整圈每 15 度、雙車道、兩種車長及整車端點角落。初次縮短過多曾讓該測試失敗，已保留安全深度後通過。

完成版本 UI 確認 `3a675fbd`，以既有隔離 origin .23 的合成進度檢查日／雨／黃昏／夜景展示視角、另一面 45 度／144 度、最低 30 度／180 度及 390×844 手機俯視。兩段低角度雨景連續截圖共 56 張，拍到車輛出入；未見生成／回收瞬間。Console error／warn 為空。測試主題沿用前輪合成 20 關備份，未實際通關 20 關，未修改使用者一般 origin 進度。

本輪未重做手動九步通關，前輪結果留在原報告；關卡、紅車出庫、通關動物、車流速度與 UI 行為未改。沒有真機效能量測。
