# 隧道主體統一與入口接地修正

2026-10-11，`feature/game-feel`，版本 `638ab521`。

使用者否決斜降側翼，並要求兩端主體一致、僅小裝飾有差異。本輪移除兩端全部斜降側翼，統一石牆分格跨度與縱向屋面立縫；完整結構原先即為等長鏡像，目前外部主體分格也一致。差異只剩入口小光帶的細分格與石材微色差。

舊側翼伸出隧道底座，底部在地面上方 0.035，造成懸空觀感；已移除。舊門框向入口外突出，現改為入口內側 0.08，深度 0.14，整個門框落在隧道自身底座範圍內。底座與道路共面修正保留，未新增延伸底座或靠偏移陰影遮掩。實體遮擋殼、車流端點、四主題／雨材質、穩定陰影、紅車出庫、動物、關卡均不變。
