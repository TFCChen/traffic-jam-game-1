# 街道整合與出庫陰影（2026-10-11）

基準版本 c8e3b199；完成版本 defc5baa。分支 feature/game-feel。

## 修正

- 紅車離場尾段的外側陰影越過原本固定 ±8 的日光陰影相機邊界。改為在光源設定更新時，固定涵蓋完整出庫範圍；不逐幀追車，不修改穩定 PCF 濾波。
- 原本追加的道路與原路面重疊，高度、標線位置與路緣不一致。改成單一連續瀝青，沿用原材質與高度、原標線位置及間距；直接取原模型的倒角石質路緣延伸兩側，底座一起延伸。新幾何在既有場景批次之前整合，保留原 GLB。
- 雨天道路使用涵蓋完整街道的世界座標濕地圖，延伸段也有固定種子的自然水坑，保留原路面的既有水坑與克制反光。
- 車流基礎速度從 2.9–4.4 提至 5.2–7.6 世界單位／秒，仍保留各趟不同加減速、六車款、隨機顏色與雙向分道。實際整趟時間依鏡頭可見道路長度而變，不應固定宣稱秒數。

## 視覺驗證

桌面 998×900：俯視 83% 出庫、展示角度 69% 日景／雨景、俯視 65% 雨景車流，以及 30°／180°／65% 反向道路。手機 390×844 雨景布局已檢查。道路上下接點不再有重疊接縫，兩側路緣與標線連續，原道路之外也可見水坑。車流六張截圖間各要求等待 400ms（另含實際截圖耗時），可見車輛迅速通過；不是嚴格定時錄影或 FPS 測量。

完成版 origin 捕捉 console error 為空。未手動逐關玩完四十關、未做真機效能測量。
