# 將玩具車庫加入主畫面

這是從網站安裝的 PWA，沒有 `.ipa`／`.apk` 安裝檔，也不需要 App Store 或 Google Play。第一次安裝必須連網打開分享網址；離線快取完成後，可遊玩已下載的內容。

## iPhone

1. 在 Safari 開啟朋友傳來的 Vercel 分享網址，等遊戲場景載入完成。
2. 點 Safari 的「分享」圖示，再選「加入主畫面」。若動作清單未顯示，往下滑或使用「編輯動作」。
3. 名稱顯示為「玩具車庫」；確認「以網頁 App 開啟」（若有出現），點「加入」。
4. 從新建立的主畫面圖示啟動遊戲。首次連線先使用原分享網址，確保 Vercel 已授予預覽存取權。

## Android

在 Chrome 開啟分享網址，點右上角「⋮」，選「安裝應用程式」或「加到主畫面」，再確認安裝。符合條件時，遊戲內的「安裝遊戲」也會直接呼叫 Chrome 安裝視窗。

## Windows

在 Chrome／Edge 開啟遊戲網址，選網址列安裝圖示，或瀏覽器選單中的「安裝玩具車庫」。若安裝入口未出現，可從桌面瀏覽器繼續遊玩。

新增部署後若分享權限要求再次驗證，請到 Vercel 對最新預覽部署重新建立「Anyone with the link」分享連結，並把新連結傳給玩家。

PWA 使用網站本身的版面、Three.js 3D 場景與遊戲資產，以獨立視窗啟動，沒有 Vercel 的標誌或固定導覽列。各裝置的 WebGL 效能仍需實機確認；PWA 安裝不會自動同步不同裝置的遊戲進度。
