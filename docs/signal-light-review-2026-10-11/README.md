# 日行燈／尾燈真實性檢查

2026-10-11，9dfa17f0，feature/game-feel。只做研究及UI檢查，沒有改src／部署。

## 來源及判讀

- [英國交通部日行燈說明](https://www.gov.uk/government/publications/daytime-running-lights/daytime-running-lights)：專用DRL是白天讓其他用路人看見車輛的信號燈，非夜間道路照明。
- [ams OSRAM後組合燈](https://ams-osram.com/applications/automotive-mobility/rear-combination-light)：紅色後位置燈和煞車燈可共用燈具、以不同亮度實現不同功能；倒車燈另列功能。
- [HELLA後燈光學](https://www.hella.com/australiansolutions/en/Products/DuraLED-Rear-Lamps-8958/)：強調寬視角可見性。

推論：日行燈／紅尾燈應以可見燈面和近處少量溢光為主，不能當縮短的道路照明燈。地面沒有通用固定投射公尺數，需視燈高／配光／地面材質／環境亮度判讀，濕地反射也不同於直接光束。這是視覺用途判讀，沒有特定車款光度量測或場景公尺校準。

## 程式與實際畫面

vehicleEffects.js：日行燈半徑上限 .85 場景單位，半角 .65，光強 .65，無空氣光束；普通紅尾燈半徑上限1.2，半角.95，penumbra .9，光強 .216×activity，煞車同範圍光強2。這些數字是光源衰減截斷半徑，不是地面光斑中心距離，也不能直接當公尺。以兩格小車長2作比較，分別約.425及.6車長。

UI臨時草稿紅車置中，日景點車、夜景點車及向前移一格放手捕捉煞車，1280×720／90／0／100%。

- [日行燈](drl-day.png)：燈面亮、地面照明很淡，整體方向合理。
- [普通尾燈](tail-night.png)：地面紅光弱，沒有明顯長投射，整體方向合理。
- [煞車燈](brake-night.png)：後方兩塊紅色地面光斑清楚可見，與車尾有間隔。視覺上仍偏聚光燈配光；若追求寫實，優先讓紅光更靠車尾、邊緣更分散，主要增加燈面亮度而非遠處地面照明。此為視覺評估，不能稱為不符任何特定法規或量測。

白色倒車燈功能應與紅尾燈區別；現程式共用後方投光池，以reverse優先切白。這輪未獨立驗證倒車畫面，不對其真實距離下結論。
