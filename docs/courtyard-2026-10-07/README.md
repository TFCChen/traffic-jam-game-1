# 正方形街區重建與自然轉向（2026-10-07）

## 場地

完整重建為 12.4×12.4 的方形微縮街區，保留中央 6×6 解謎盤面。四周安排石材鋪面、深色細金屬圍欄、磚牆咖啡店、遮棚、木質長椅、餐桌與棚架、細葉植栽、街燈及道路排水細節。道路、出口與盤面共用相同高度，不再使用前一輪的執行時擴建路面。

保留金屬、木材與玻璃各自的材質反應，日夜場景共用相同物件。鋪面接縫不投射細碎自陰影；程序圖集改用亂數高位元取樣，避免低位元周期導致重複像素累积成斑點。

畫面保留完整細葉幾何，植栽陰影改用低多邊形樹冠輪廓。陰影輪廓的三角形量不到葉片幾何的五分之一；普通畫面禁止這些輪廓寫入顏色或深度，不會遮住真正的植栽。輪廓合併為單個 instanced mesh，初始化後保持靜態。

Blender 原檔為 `art/street-courtyard.blend`；`scripts/build_environment.py` 可獨立重建場地。GLB 約 4.8 MB，頂點位置維持浮點精度，法線採 16-bit、顏色採 8-bit 正規化儲存，使用 `KHR_mesh_quantization`。車輛模型原檔與 GLB 保留既有版本。

## 出庫

轉彎曲率逐漸增加後回到零，取代直線突然接上固定半徑圓弧。前輪依曲率轉動並回正；車身小幅向彎外側傾，輪胎滾動、排氣與車燈跟隨車身。速度漸起、彎中放慢，街道末段漸停並亮起煞車燈。車子持續存在街道上，不在道路中間突然消失。

結果介面等待完整演出及鏡頭還原，保留低動態模式，重玩／下一關／返回編輯器流程保持一致。

- 單元與模型檢查：40 關模型映射、遊戲規則、儲存、編輯器、車身與燈光、出庫位置／方向／前輪連續性、圍欄淨空、方形場地及全程柏油支撐。
- 正式建置及離線資產快照通過。
- `verify-courtyard.mjs`：預設俯視、完整場地、咖啡店放大、黃昏、夜景、25° 低角度、反向視角與 390×844 手機尺寸；無瀏覽器渲染錯誤。
- 實際檢視截圖，修正材質斑點與球狀樹冠。
- `verify-exit.mjs`：原生滑鼠、模擬手機觸控、低角度出庫、前輪轉向與回正、結果時機、重玩還原、試玩返回編輯器，以及正式第一關九步通關後進入第二關。
- 靜止場景 30 FPS 上限、靜止陰影更新 0、離屏繪製 0。正式遊玩期間的提交與 GPU 計時樣本存於 `results.json`。

手機畫面與觸控為桌面 Chrome 模擬，不能代表實體 iPhone / Android 的硬體效能。完整畫面證據、角度設定與效能取樣位於本資料夾。

正式第一關拖曳及出庫混合取樣（300 幀）中，陰影輪廓優化前後三角形中位數由 566,742 降為 496,982，p95 由 849,020 降為 731,792。GPU 中位數約 24.1／24.2 ms，沒有明顯時間改善；最終 CPU 提交 p95 5.0 ms、GPU p95 27.9 ms。這些是此測試環境的短時樣本，不能當作實機或 60 FPS 保證；後續應以實體手機的 GPU 與畫質選項繼續調校。
