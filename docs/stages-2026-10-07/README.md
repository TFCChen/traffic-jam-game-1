# 燈具、關卡編輯器、通關流程

## 完成範圍

- 九種車輛增加燈具結構：跑車曲面燈殼與光學薄層、乘用車投射式透鏡與獨立日行燈、商用車分區反射杯，尾燈使用分層光條。沿用既有燈光時機及有限數量的實際投射光。
- 編輯器改成桌面側邊工具面板／手機底部工具面板。八種非主角車型可直接選擇，方向由兩個按鈕切換；第一台紅車仍固定出口列、水平兩格。
- 3D 半透明放置輪廓、合法起點、無效位置紅色預覽。拖拉放置使用釋放位置；兩點放置須符合選定車型的長度及方向。2D 備援也提供合法位置與輪廓。
- 驗證結果放在工具面板內，避免遮住儲存／試玩按鈕。草稿、復原、重做、驗證、儲存、試玩沿用原有資料流程，新增 Ctrl/⌘ Z、Shift Z、Ctrl Y 快捷鍵，輸入名稱時保留原生文字復原。
- 出庫先升起出口柵欄，紅車加速駛出，鏡頭輕跟隨並歸位，然後呈現結果。最佳解顯示「完美出庫」、下一關名稱及淡出切換；減少動態模式跳過出庫跟拍。

## 驗證

`npm test`：遊戲引擎、九種資產、四十關車型映射、燈光、懸吊、儲存、鏡頭、接地陰影及完整放置範圍全部通過。

`npm run build`：重新求解並重播四十個官方關卡，建置版本化離線資產。

`scripts/verify-stages.mjs`：真實滑鼠與 Chrome 觸控輸入驗證合法紅車起點（5 個）、無效預覽、車型選擇、兩點放置、復原／重做與快捷鍵、觸控拖拉放置、觸控點驗證按鈕、試玩／重玩、官方第一關最佳解、下一關切換、低動態模式。按鈕以原生輸入點擊並檢查沒有被遮住。測試後還原測試瀏覽器的儲存資料。

`scripts/verify-stage-models.mjs`：九種車型近看截圖、滑鼠及觸控移車／復原、渲染量測與 console error 檢查。手機視窗及觸控為桌面 Chrome 模擬，不代表 iPhone 或 Android 實機 GPU 效能。

畫面檢查修正了驗證卡遮擋工具、桌面畫布寬度、手機方向按鈕超寬、切換車型首個事件清除預覽，以及跑車透鏡突出曲面的問題。

截圖與量測 JSON 位於同目錄。更廣泛的街景／內裝美術打磨留待這些操作階段完成後再進行。

## 效能與版本

最終應用程式版本 `bd3fcf25`；模型快取版號 `ec48ec17ff793c74`。桌面 1440×950 精緻畫質：90 次繪製呼叫、76 個幾何資源、14 個紋理資源（均與前輪細節版本相同）；282,210 個三角形，GPU 中位 21.21 ms。前輪細節版本為 269,598 個三角形、GPU 中位 20.02 ms；新增燈具約增加 4.7% 三角形，單次桌面量測約增加 1.2 ms GPU 時間，非嚴格效能基準。
